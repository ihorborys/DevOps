# 🚀 AWS Infrastructure with Terraform (Lesson 5)

Цей проєкт демонструє створення **модульної інфраструктури в AWS** за допомогою Terraform.  
Включає:

- віддалений бекенд для зберігання стейту
- мережеву інфраструктуру (VPC)
- реєстр Docker-образів (ECR)

---

## 🛠 Опис модулів

### 1️⃣ s3-backend

Модуль створює надійне сховище для `terraform.tfstate`.

- **S3 Bucket**
  - Зберігає файл стейту
  - Увімкнено версіювання

- **DynamoDB Table**
  - Використовується для **State Locking**
  - Запобігає одночасним змінам інфраструктури

---

### 2️⃣ vpc

Модуль для розгортання ізольованої мережі в AWS.

- **VPC**
  - Основна логічна мережа
  - Підтримка DNS

- **Subnets**
  - Публічні (через Internet Gateway)
  - Приватні (ізольовані)
  - Рознесені по Availability Zones

- **Routing**
  - Таблиці маршрутизації
  - Internet Gateway для доступу в інтернет

---

### 3️⃣ ecr

Модуль для створення Amazon Elastic Container Registry.

- Зберігання Docker-образів
- Автоматичне сканування на вразливості (`scan_on_push`)

---

## 🚀 Команди для керування проєктом

### Ініціалізація

*terraform init*  
Ініціалізує проєкт, завантажує провайдери та модулі.


### Планування змін

*terraform plan*  
Показує, які ресурси будуть створені, змінені або видалені.



### Застосування змін

*terraform apply*  
Створює або оновлює інфраструктуру в AWS відповідно до конфігурації.


### Видалення інфраструктури

*terraform destroy*  
Видаляє всі створені ресурси.
